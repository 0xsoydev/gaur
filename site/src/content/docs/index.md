# Introduction

Gaur is a terminal user interface (TUI) for Arch Linux package management. It aims to provide a fast, beautiful, and interactive way to manage your system packages.

## Getting Started

To install Gaur, you can use `go install`:

```bash
go install github.com/prbhtkumr/gaur@latest
```

## Features

- **Fuzzy Search**: Find packages instantly.
- **Batch Operations**: Mark multiple packages for installation or removal.
- **Dashboard**: Monitor your system stats and disk usage.
- **Themes**: Customize the look of Gaur to match your terminal.
