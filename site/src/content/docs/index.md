# Gaur

**Gaur** is a high-fidelity, interactive terminal user interface (TUI) designed to make Arch Linux package management both powerful and visually striking. Built with the [Bubble Tea](https://github.com/charmbracelet/bubbletea) framework, it provides a seamless bridge between raw command-line power and modern interface design.

## Core Philosophy

Gaur is designed for "terminal purists" who demand speed and total control without sacrificing aesthetics. It doesn't just run commands; it creates an immersive environment for managing your system's package ecosystem.

## Key Features

- **Fuzzy Search:** Powered by `fzf` for lightning-fast matching.
- **Dynamic Helper Support:** Seamlessly switch between `paru` and `yay`.
- **System Dashboard:** Real-time stats on disk usage, orphan packages, and cache hogs.
- **Batch Operations:** Mark multiple packages and process them all at once.
- **XDG Compliance:** Respects your system configuration out of the box.
